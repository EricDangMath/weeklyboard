# 日历订阅链接与拖拽复制

## 日历链接

顶部 **订阅链接** 可开启一个只读 ICS 订阅。选择名称、日程时区、图层和是否包含截止提醒，然后生成并复制链接。

- 这是完整日历订阅，不是一次性下载。每次读取都从 SQL 数据库生成，新增、修改、删除日程都会反映在下一次读取中。
- 所选图层中已保存的日程、每周固定安排、全天事项、截止提醒会导出。尚未确认的智能规划草案、涂色、任务池和私密来源订阅 URL 不会导出。
- 周期日程使用每周重复规则和时区定义，夏令时前后保持当地时间。无日期的旧日程以首次开启订阅所在周为锚点。
- 苹果/Google/Outlook 等客户端决定刷新周期。日历提供 30 分钟刷新提示，但不能保证客户端立即刷新。此功能是周看板到外部日历的单向同步，不接收外部修改。
- 使用客户端的“订阅日历 / 通过 URL 添加”功能，而不是下载后导入文件。
- 拥有链接即可读取所选日程，请勿公开链接或提交到 GitHub。可随时停用；再次开启生成新链接。停用不能删除他人已经下载的副本。
- 账号备份不包含订阅访问凭据。恢复备份会停用对外分享，避免无意分享恢复的数据；需手动重新开启。

## 跨设备部署

当前开发环境保持 `DEBUG_MODE=true`，且只监听本机。`127.0.0.1` 链接仅可在这台电脑访问，不可让 iCloud、Google 或另一台设备订阅。不要为此把当前 DEBUG 工作区直接暴露到公网。

在单独配置的正式后端使用 Node.js 24 LTS，并执行 `npm ci --prefix server` 安装锁定依赖。公开部署须先完成账号隔离、`DEBUG_MODE=false`、强 `JWT_SECRET`、数据库持久化及备份，再用 HTTPS 反向代理连接 API。不要让代理访问日志记录 `/api/calendar/feeds/` 后的访问令牌；此路径应关闭日志或脱敏，且不要缓存它。

假设正式 API 为 `https://your-domain.example/api`：

```dotenv
# 后端 server/.env，示例域名必须替换
PUBLIC_CALENDAR_BASE_URL=https://your-domain.example/api

# 前端构建时的环境变量，修改后重新构建
VITE_API_BASE_URL=https://your-domain.example/api
```

`PUBLIC_CALENDAR_BASE_URL` 是完整 API 基址（包含 `/api`，不带结尾斜杠），不是前端网址。重新启动后端后，订阅设置会显示对应的 HTTPS 地址；该配置不会自动部署服务器。前端优先使用 `VITE_API_BASE_URL`，兼容已有 `VITE_API_BASE`；两者均未配置时继续使用同源 `/api`，保留 remake 分支现有部署方式。

链接路径 `/api/calendar/feeds/<随机令牌>.ics` 必须允许外部日历直接 GET，不要在此路径加登录跳转；其他 API 保持原有认证。先用不含私密信息的测试日程验证，确认无令牌时无法读取，停用后旧 URL 返回 404，再分享真实日历。

## 拖拽复制

鼠标悬停日程后，右下角显示复制手柄。拖到另一时间或日期后松开，生成同名、同图层、同分类、同时长的独立日程，原日程不变。拖拽有落点预览，按时间网格吸附；冲突日程继续左右分栏。

副本可以正常移动、修改和删除，不继承原事件的重复规则或订阅锁定。来自固定安排、订阅源的副本只写入当前周，不修改源日历；关联任务保留，实际图层副本正常参与统计。按 Escape 或在网格外松开可取消。只点手柄而不拖动不会新增。

键盘聚焦复制手柄后按 Enter 可打开预填的新增面板。日程底边中间仍用于调整结束时间。

## 实现与验证

- `server/calendar-publish.js`：认证管理接口、可撤销访问令牌、稳定 UID、更新序号、按账号和图层导出。
- `ical-generator` 负责标准 ICS 序列化；`temporal-polyfill` 和 `@touch4it/ical-timezones` 负责日期时区与 VTIMEZONE。参考 [ical-generator 文档](https://github.com/sebbo2002/ical-generator#-date-time--timezones)。
- `src/CalendarPublish.jsx`：订阅管理入口。`src/EventCopy.jsx` 与 `src/event-copy.mjs`：复制手柄、预览、取消与副本字段约束。
- `npm test`：含订阅权限隔离、图层过滤、更新/删除、停用/重新开启、备份恢复、全天和夏令时、复制独立性测试。
